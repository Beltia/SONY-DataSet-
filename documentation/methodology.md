# Methodology

## 1. Data acquisition

The project uses the supplied Kaggle Sony Group Corporation historical stock dataset.

## 2. Data validation

The dataset was checked for:

- Missing values
- Duplicate dates
- Invalid data types
- Invalid price relationships
- Negative trading volume
- Date range consistency

The supplied data contains 3,179 rows, six source columns, no missing values and no duplicate dates.

## 3. Transformation

Additional variables were created to support analysis:

- Daily price change
- Daily percentage return
- Intraday range
- Moving averages
- Rolling volatility
- Calendar attributes

## 4. Analysis

The project uses both Excel and PostgreSQL. Excel supports formulas, aggregation and dashboarding. SQL supports reproducible analytical queries and demonstrates database skills.

## 5. Interpretation

Results are interpreted as historical observations. No attempt is made to guarantee future returns or provide personalised investment recommendations.
